2Maths#

Maths is rendered, not imaged. multiline, flalign, alignat, gather, equation, align, cases, array and pmatrix all typeset:

F(g)=∫M​(R+∣∇f∣2)e−fdV.(2.1)

Cross-references resolve, so (1) works. With \numberwithin{equation}{section} in the source, equations number inside their section – (2.1), (3.1) – rather than running on for the whole paper.

2.1What is not rendered#

An environment the converter does not know is kept as source and labelled, never dropped. A figure that will not compile is shown as the code that would have produced it, with the reason.

3Figures#

3.1Graphics#

An extension-less \ includegraphics resolves the way LaTeX resolves it. Vector artwork is rasterised at build time, because a PDF inside an <img> displays nothing, and trim is honoured while that happens.

3.2TikZ#

TikZ is compiled against the source's own preamble, so a figure looks the way it was drawn: its macros, its styles and its colour names all resolve.

A build compiles it if it finds a TeX engine, and says so when it does not. With no engine the drawing is shown as the source above, labelled as such.

4Layouts#

Five layouts, each usable with any palette.

paper

Serif, print-inspired, generous measure, contents rail. For a paper.

notes

Sans-serif, wide measure, skimmable. For lecture notes.

slides

Scroll-snap deck. Sections become dividers, beamer frames become slides.

docs

Sections as cards, no rail. For a documentation page.

landing

A front page: the name set low, example buttons, a contents rail below the hero.

5Decks#

A beamer frame becomes a section, numbered the way beamer numbers it. Each slide is labelled Slide N of M in document order; a [plain] frame is not counted, because an opening card or a closing The End carries no number in the published deck either. A \ sectiontitleframe is counted, and renders as a real heading.

Overlays are flattened. There is no presenter on a web page to reveal them.

6Palettes and tokens#

A palette is colour and type; a layout is structure. Six palettes ship, each with a light and a dark half, so a page follows the reader's system. There is no toggle in the chrome.

Colour and font tokens come from the palette: bg, bg-raised, bg-sunken, bg-tint, ink, ink-soft, ink-faint, line, line-soft, accent, accent-soft, accent-ink, accent-2, mark, shadow, the six emph-* colours, the tok-* colours used by code, and the serif, sans and mono stacks.

Structural tokens come from the layout: measure, rail, gutter, masthead-h and the type scale.

6.1What is measured, and what is yours#

A palette states a ground and a character. The ramps around it are derived and then checked, not chosen by eye: text levels are ordered by contrast against the ground, a card is lighter than the page in both modes, and every level clears WCAG AA on every surface it lands on. That is why a dark flavour's bg-raised is not its own mantle – Catppuccin's mantle is darker than its base, which made a card a hole in the page.

A token you pass yourself is never second-guessed. The repair runs over the palette first, so {"accent": "#e11"} is the red you asked for.

7The configuration file#

JSON, or a module exporting an object or a function. Found by walking up from the working directory; extends names a preset path or package.

7.1The same file as a module#

A module may export a function, which is how a build generates its configuration instead of repeating it. A preset is a module too, and a file that extends one is handed the preset's result to change.

7.2Keys#

theme

the layout name.

palette

a name, or {light, dark} for a pair.

tokens

colour, type and metric overrides, merged over the layout's.

css

extra stylesheets, appended after the layout's own – the supported way to restyle without forking a theme.

template

a path replacing the HTML shell. The shell is a template, so the whole page is replaceable rather than only decorated.

nav

the masthead menu. An entry with items is a dropdown. Left unset, a multi-page build links its own documents instead.

footer

false for a line of small print instead of the site footer, which is what a lone converted document wants.

hero

"front-matter" lifts the title, the author and the first paragraph into the hero, so the contents starts level with the first section.

wordmarkHero

draw the mark as the title instead of setting the title as a heading.

notice

an editorial note above the content, for when a conversion had to change something.

xrefs

where \ dlcref resolves to, as a map from key to the text to print. See References to a sibling deck.

motion

"on" or "off". "auto" is not an alias for "on".

figures

{delegate: false} stops the build shelling out to a TeX engine, for a build that must not reach the network or that wants the same bytes on a machine with TeX and one without. On by default.

head

scripts

extra markup, or functions returning it.

An unknown key is reported rather than ignored, because a typo is silent otherwise and the symptom is a setting that does not apply.

8What a conversion is not#

The source that was written is the source that is typeset. Nothing is rasterised from a PDF of the document, because a PDF has already thrown away the structure that makes a page worth reading: the headings are not headings, the references are not links, the equations are pictures of equations.

So a converted paper is a conversion, not a transcription, and no claim is made over the work itself. Where something had to change to get a page out at all, notice is how that gets said on the page.

9Getting a page out of a real paper#

  1. Give it the source: latex2web paper.tex site/, then open site/paper.html.

  2. Pick a layout for what it is. A paper is paper, a deck is slides, notes are notes.

  3. A figure that comes out as source means no TeX engine was found to compile it. Installing one is all it takes.

  4. If a section came out wrong, check whether the source stars it. \ section* is unnumbered, and numbering it shifts every equation after it.

  5. If something is missing, say so on the page with notice rather than leaving the reader to find the gap.

One command turns a LaTeX source into a folder of static files. Nothing to install, nothing to serve, nothing to run in a browser.
