3What it can't do#

λtex2web isn't a TeX engine and doesn't plan on being one. There is unfortunately then no typesetting, no package resolution, and no expansions beyond \ newcommand and \ def in your own preamble. Anything it doesn't recognised will be spit out as text.

Also:

  • TikZ needs an engine. Diagrams are compiled with pdflatex when installed, so a figure looks like the source. With no engine on the machine they appear as source.

  • Vector figures are rasterised. A PDF inside an img element will show nothing, and is why the Ricci flow page is megabytes large.

All three examples featured on this cite went through the same command that built this page (though with different configurations), from the original LaTeX files off arxiv. Please refer to the documentation page for more information.
